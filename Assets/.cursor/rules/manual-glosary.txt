Util_ -> Utilidades, funcionalidad unica
SDB_ -> Base de datos simulada, guarda datos primitivos o visuales para usarlos desde referencias estáticas
ref_ -> referencias, intermediario entre un Manager y los objetos del mundo, guarda referencias de un apartado único
I_ -> Interfaces
[no prefix] -> Individual script, uso preferente en sistemas de bajo alcance

Manager -> Maneja interacciones, scripts y tiene todo el "grueso" de un sistema de media-alta complejidad
ControlCenter -> Cerebro de la app, centraliza managers y los conecta entre sí, maneja fallbacks, persiste entre escenas, entre otros

XRS -> XR Suplement, suplemento para sistemas de paquetes XR

SimulationOrchestratorManager -> Orquesta flujo S1-S2-S3 de la simulacion LOTO (Slice 1+)
SimulationSessionManager -> Crea y persiste SimulationSessionContext al iniciar simulacion
SyncQueueManager -> Cola JSON offline para sync con backend SafeMining (PendingSyncQueue.json)
ISimulationBackendAdapter -> Interfaz para adapters Offline y SafeMining REST
OfflineBackendAdapter -> Adapter sin HTTP; solo encola en persistentDataPath
SafeMiningBackendAdapter -> Stub REST para Fase 7; endpoints /api/vr/sessions/*
loto_obj_epp_selection -> ID objetivo 20% escenario EPP
loto_obj_epp_defect -> ID objetivo 10% escenario EPP
loto_obj_hazard_report -> ID objetivo 25% escenario inspeccion
loto_obj_loto_sequence -> ID objetivo 35% secuencia LOTO
loto_obj_zero_energy -> ID objetivo 10% verificacion energia cero
loto_simulation -> ID escena SimScore unica para simulacion LOTO completa
